# AIOps — topology-aware network anomaly detection and root-cause localization

This repository organizes a research project evaluating graph-based network anomaly detection, topology-aware diagnosis, and root-cause localization. The three base research papers and research methodology are under `researchPapers/`; reproduction source code and related work are under `baselineReproduction/`.

**Begin here:** [Baseline reproduction — beginner setup guide](baselineReproduction/setup/README.md).

Read the setup guide **before installing anything**. It provides per-paper prerequisites, GPU/CPU commands, data acquisition instructions, precise experiment commands, validation status, troubleshooting and small Git commits. The third paper's author source/data are not yet available; its placeholder does not claim to implement the model.

**Research integrity:** Distinguish synthetic smoke tests, author-equivalent paper reproduction, and your own experiments. Do not report bundled reference tables as newly computed results.
